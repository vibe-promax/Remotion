# Reference Editorial Motion System

## Purpose

Reusable Remotion direction for short vertical editorial motion graphics based on the supplied reference video.

The system preserves the **motion language**, not the reference's story or exact objects.

## Visual DNA

- 9:16 vertical composition
- Warm off-white / light-gray background
- Large translucent angular zigzag forms in the background
- Elegant high-contrast italic serif typography, Didot-like
- Small italic editorial eyebrow text
- Very limited accent colors: black, red, blue, lime/yellow
- Black faceted geometric objects entering from corners and acting as foreground wipes
- Floating rounded photographic/3D cards with soft, deep shadows
- Objects feel physical, slightly imperfect and premium rather than flat UI
- Strong scale changes and subtle camera-like push-ins
- Gaussian-like blur during scene entrances/exits
- Soft vignette and atmospheric depth
- Large negative space
- One visual idea per scene
- Text is short and editorial; never turn narration into full subtitles

## Motion Language

1. Start scenes slightly blurred and oversized.
2. Resolve into sharp typography/object composition.
3. Let one main object or text element move at a time.
4. Use slow push-ins, scale reveals, small rotations and vertical rises.
5. Use corner faceted objects as transition anchors.
6. Use object/card pass-throughs and blur crossfades instead of generic transitions.
7. End scenes with a clean visual state that can visually morph into the next scene.
8. Avoid glitch, bounce, excessive parallax, UI-template aesthetics and constant motion.

## Typography

Primary: Didot-like high-contrast italic serif.
Secondary: small italic serif editorial labels.
Accent: occasional handwritten/display treatment when the story benefits from it.

Use short phrases such as:
- Attention
- Trust
- Product
- Service
- Brand
- Audience
- Business Asset

Do not place the complete narration on screen.

## Visual Metaphor Rule

For every script beat, choose a physical visual metaphor instead of literal subtitle animation.

Examples:

- Attention + Trust → connected network / nodes
- Audience → human/creator card + network
- Years to build audience → progress line / timeline
- Product → premium product card
- Service → service/interface card
- Brand → dark premium brand card
- Business asset → physical card/object representing stored value

## Scene Formula

Each scene should follow:

**Eyebrow → short editorial headline → physical visual → micro-motion → transition anchor**

Target scene duration: 1–3 seconds.

## Reusable Production Requirement

When a new script is supplied:

1. Keep this visual system.
2. Extract only the strongest 1–5 word phrases.
3. Convert each major idea into a new visual metaphor.
4. Never copy the reference's exact objects, wording, creator handles or watermark.
5. Keep the same typography, spacing, depth, camera energy, blur transitions and faceted-object language.
6. Generate the new story as a continuous editorial film, not as unrelated template slides.
