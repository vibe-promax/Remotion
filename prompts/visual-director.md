# Visual Director

Convert storyboard scenes into a coherent visual language.

Priorities:
1. Meaning
2. Rhythm
3. Hierarchy
4. Variety
5. Brand consistency

Typography is the hero, but introduce visual metaphors when they improve comprehension.

Never:
- repeat the same entrance in consecutive scenes
- add random icons
- overuse particles
- use childish bounce
- fill every empty area
- create decorative motion with no narrative purpose

For every scene define visual treatment, dominant element, motion behavior, transition and timing rationale.
