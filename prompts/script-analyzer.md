# Script Analyzer

Analyze the supplied script as a professional short-form motion designer.

Return JSON matching schemas/storyboard.schema.json.

1. Identify hook, thesis, supporting points, examples and CTA.
2. Estimate speaking duration at natural narration speed.
3. Mark emphasis words and phrases.
4. Divide the script into semantic scenes.
5. Choose a different visual treatment when the meaning changes.
6. Do not use kineticText for every scene.
7. Use charts for statistics, timelines for chronology, UI frames for interfaces, diagrams for systems and editorial cards for concise conceptual statements.
8. Keep each scene visually understandable without requiring every spoken word to be on screen.
9. Preserve the exact spoken script unless rewriting is explicitly requested.
