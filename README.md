# Saafi Smart — Website

A responsive single-page brand website for Saafi Smart, rebuilt as a clean static site.

- Brand palette: Deep Navy #060C1C, Midnight Black #010512, Bright Yellow #FFE600, White.
- Sections: services, approach, packages, contact.
- Mobile-first responsive layout, accessible reduced-motion behavior, lightweight CSS/JS.
- No framework or build step: GitHub Pages can serve `index.html` directly.
